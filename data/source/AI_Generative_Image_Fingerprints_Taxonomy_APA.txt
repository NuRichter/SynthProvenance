CATATAN TERMINOLOGI
===================
Istilah "fingerprint", "artifact", "trace", "signature", "cue", dan "watermark" tidak selalu dipakai secara identik di seluruh literatur.

Secara praktis:
- Artifact = jejak/ketidaksempurnaan yang muncul dari proses sintesis atau pipeline generasi.
- Fingerprint = representasi atau pola yang relatif stabil dan dapat dipakai untuk membedakan atau mengatribusikan model/source/proses generasi.
- Trace = jejak forensik yang tersisa pada output.
- Signature = istilah umum untuk pola identitas.
- Watermark = sinyal yang sengaja ditanam untuk provenance, attribution, ownership, atau detection.
- Detector representation = fitur/embedding yang dipelajari atau digunakan detector. Ini tidak otomatis sama dengan intrinsic fingerprint.
- C2PA / Content Credentials = provenance/authenticity infrastructure berbasis metadata dan tanda tangan kriptografis, bukan intrinsic image fingerprint.

5C. LANGUAGE-GUIDED FORENSIC REPRESENTATION
--------------------------------------------
LASTED:
- LanguAge-guided SynThEsis Detection
- Language-guided Synthetic Image Detection
- Language-guided Contrastive Learning
- Image-Text Contrastive Forensics
- Text-Guided Forensic Representation

Konsep:
- Synthetic/real semantics dipasangkan dengan textual prompts.
- Detection diperlakukan sebagai identification/representation problem, bukan hanya binary classification.

5D. MULTILID / LOCAL INTRINSIC DIMENSIONALITY
----------------------------------------------
Istilah:
- LID
- Local Intrinsic Dimensionality
- multiLID
- Multi-Local Intrinsic Dimensionality
- LID Feature Vector
- Intrinsic-Dimension Signature
- Latent-Manifold Geometry Features
- Neighborhood Growth-Rate Features

Paper:
"Detecting Images Generated by Deep Diffusion Models Using Their Local Intrinsic Dimensionality"

Konsep:
- Mengukur geometri/manifold behavior dalam latent feature space.
- multiLID mempertahankan informasi pertumbuhan jarak ke beberapa nearest neighbors, bukan hanya satu scalar statistic.
- Cocok dikategorikan sebagai geometric/manifold forensic signature.

6. DIFFUSION-SPECIFIC RECONSTRUCTION FINGERPRINTS
------------------------------------------------------------

Walaupun secara konseptual dapat masuk ke intrinsic fingerprints, subfamily ini layak dipisahkan dalam literature database karena sangat sering muncul sebagai kategori tersendiri.

6A. DIRE
-------
DIRE = DIffusion Reconstruction Error

Istilah:
- Diffusion Reconstruction Error
- Reconstruction-Based Diffusion Detection
- Diffusion Inversion/Reconstruction Cue
- Reconstruction Residual
- Diffusion Reconstruction Fingerprint

Ide:
- Input image direkonstruksi menggunakan pretrained diffusion model.
- Perbedaan input versus reconstruction menjadi forensic representation.
- Diffusion-generated image cenderung lebih mudah direkonstruksi oleh diffusion model yang relevan dibanding real image.

6B. AEROBLADE
------------
AEROBLADE = Training-Free Detection of Latent Diffusion Images Using Autoencoder Reconstruction Error

Istilah:
- Autoencoder Reconstruction Error
- AE Reconstruction Error
- LDM Autoencoder Fingerprint
- Latent Reconstruction Cue
- Training-Free LDM Detection

Ide:
- Menggunakan autoencoder yang merupakan komponen inheren latent diffusion model.
- Perbedaan reconstruction quality antara generated dan real images dipakai untuk detection.

6C. SYNTHBUSTER
---------------
Istilah:
- Fourier-Domain Diffusion Detection
- Spectral Diffusion Detection
- Fourier Artifact Detection
- Diffusion Spectral Cue

Fokus:
- Fourier/spectral traces yang dapat membedakan diffusion-generated images dari real images.

7. KLASIFIKASI SILANG: JANGAN MENCAMPURKAN ISTILAH
------------------------------------------------------------

INTRINSIC
- Sumber: proses generasi secara alami.
- Tidak harus ada desain watermark.
- Contoh: GAN fingerprint, diffusion reconstruction cue, architecture-level fingerprint.

CAUSAL
- Sumber: model fingerprint yang diformulasikan dengan hubungan provenance -> trace secara kausal.
- Fokus: content/style disentanglement, causal decoupling, counterfactual evaluation.
- Contoh: Causal Fingerprints of AI Generative Models.

SPECTRAL
- Sumber representasi: distribusi frekuensi/spektrum.
- Dapat menjadi intrinsic cue atau detector feature.
- Contoh: FFT, DCT, DWT, spectral decay, high-frequency mismatch.

PROACTIVE / ARTIFICIAL
- Sumber: sinyal sengaja ditanam.
- Contoh: Artificial Fingerprinting, ProMark, Stable Signature, Tree-Ring, Gaussian Shading, SynthID.

DETECTOR-SPECIFIC
- Sumber: representasi yang digunakan detector.
- Contoh: CLIP, DINO, multiLID, contrastive embedding.
- Tidak otomatis merupakan fingerprint model yang causal atau intrinsic.
